# 67-70 热部署

```
pom.xml
src/main/resources/
├── application.yml
├── application-dev.yml
└── application-prod.yml
src/main/java/com/example/demo/controller/
└── TestController.java
```

## 原理

双类加载器：BaseClassLoader（加载第三方 jar，不变） + RestartClassLoader（加载项目代码，变更时销毁重建）。

| 模式 | 触发 | 场景 |
|------|------|------|
| 手工 | `Ctrl+F9` 编译 | 不想频繁重启 |
| 自动 | `Ctrl+S` 保存 | 追求效率 |

## pom.xml

```xml
<!-- 热部署依赖 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <!-- 仅运行时生效，打包不打入 jar -->
    <scope>runtime</scope>
    <!-- 不传递给其他模块 -->
    <optional>true</optional>
</dependency>

<!-- 打包时排除 devtools，双重保险防止带到生产环境 -->
<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
            <configuration>
                <excludes>
                    <exclude>
                        <groupId>org.springframework.boot</groupId>
                        <artifactId>spring-boot-devtools</artifactId>
                    </exclude>
                </excludes>
            </configuration>
        </plugin>
    </plugins>
</build>
```

- **必须**：`File → Settings → Compiler` → 勾选 `Build project automatically`
- **自动模式额外**：`Ctrl+Shift+Alt+/` → Registry → 勾选 `compiler.automake.allow.when.app.running`

## 场景

第三方Bean（`ThreadPoolExecutor`、`RestTemplate`等）无法直接加 `@ConfigurationProperties`，拆成「属性类 + 配置类」两步走。

## application.yml

```yaml
thread:
  pool:
    # 短横线写法（推荐），也支持 core_size / coreSize / coresize
    core-size: 10           # 核心线程数
    max-size: 50            # 最大线程数
    queue-capacity: 200     # 阻塞队列容量
    keep-alive: 3000        # 空闲线程存活时间（毫秒）
```

## prop/ThreadPoolProp.java

```java
package com.example.demo.prop;

import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;

@Data
@ConfigurationProperties(prefix = "thread.pool") // 绑定 yml 中 thread.pool 下的配置
public class ThreadPoolProp {
    private Integer coreSize;       // 核心线程数
    private Integer maxSize;        // 最大线程数
    private Integer queueCapacity;  // 队列容量
    private Long keepAlive;         // 空闲存活时间（毫秒）
}
```

## config/ThreadPoolConfig.java

```java
package com.example.demo.config;

import com.example.demo.prop.ThreadPoolProp;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import java.util.concurrent.*;

@Configuration  // 声明为配置类，启动时执行 @Bean 方法
public class ThreadPoolConfig {

    @Bean  // 方法返回值交给 Spring 容器管理
    public ThreadPoolExecutor threadPoolExecutor(ThreadPoolProp prop) {
        // 使用 yml 中的配置参数创建线程池
        return new ThreadPoolExecutor(
            prop.getCoreSize(),                              // 核心线程数
            prop.getMaxSize(),                               // 最大线程数
            prop.getKeepAlive(), TimeUnit.MILLISECONDS,      // 空闲存活时间
            new ArrayBlockingQueue<>(prop.getQueueCapacity()), // 有界阻塞队列
            Executors.defaultThreadFactory(),                 // 默认线程工厂
            new ThreadPoolExecutor.AbortPolicy()              // 拒绝策略：抛异常
        );
    }
}
```

## 松散绑定规则

yml 配置名和 Java 属性名**不需要完全一致**，SpringBoot 自动兼容：

| yml 写法 | 示例 | Java 属性 |
|---------|------|-----------|
| 短横线（推荐） | `core-size` | `coreSize` |
| 下划线 | `core_size` | `coreSize` |
| 驼峰 | `coreSize` | `coreSize` |
| 全小写 | `coresize` | `coreSize` |

> 硬性规则：Java 属性必须驼峰；大小写不匹配会失败（`Core-Size` → `coreSize` ✗）

## 核心注解

| 注解 | 位置 | 作用 |
|------|------|------|
| `@ConfigurationProperties(prefix)` | 属性类 | yml → 字段映射 |
| `@Configuration` | 配置类 | 声明配置类，执行 `@Bean` 方法 |
| `@Bean` | 方法 | 返回值加入容器 |

```java
package com.example.demo.prop;

import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotNull;
import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.validation.annotation.Validated;
import java.time.Duration;

@Data
@Validated  // 开启校验（关键！不加校验注解不生效）
@ConfigurationProperties(prefix = "thread.pool")
public class ThreadPoolProp {

    @NotNull(message = "核心线程数不能为空")
    @Min(value = 1, message = "核心线程数不能小于1")
    private Integer coreSize;       // 核心线程数，至少为 1

    @Min(1) @Max(200)               // 范围 1~200
    private Integer maxSize;        // 最大线程数

    @NotNull
    private Duration timeout;       // 超时时间，不能为 null
}
```

# 75 进制数据转换

```
src/main/java/com/example/demo/

│   └── DemoConfig.java
└── DemoApplication.java
src/main/resources/
```

## 规则

YAML 解析器根据前缀自动识别进制 → 转十进制：

| 前缀 | 进制 | 示例 |
|------|------|------|
| `0b` | 二进制 | `0b101` → 5 |
| `0` / `0o` | 八进制 | `011` → 9 |
| `0x` | 十六进制 | `0x0a` → 10 |
| 无 | 十进制 | `11` → 11 |

> 坑：工号 `00123` 被当成八进制 → 值变成 83。**加双引号** `"00123"` 即可避坑。

## application.yml

```yaml
demo:
  binary-num: 0b101            # 二进制 → 十进制 5
  oct-num: 011                 # 八进制 → 十进制 9
  hex-num: 0x0a                # 十六进制 → 十进制 10
  dec-num: 11                  # 普通十进制 → 11
  wrong-job-no: 00123          # 坑：0开头被当八进制转成 83
  right-job-no: "00123"        # 正确：双引号强制字符串，保留原值
```

## prop/DemoProp.java

```java
package com.example.demo.prop;

import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;

@Data
@ConfigurationProperties(prefix = "demo")
public class DemoProp {
    private Integer binaryNum;     // 二进制解析后的十进制值
    private Integer octNum;        // 八进制解析后的十进制值
    private Integer hexNum;        // 十六进制解析后的十进制值
    private Integer decNum;        // 普通十进制
    private Integer wrongJobNo;    // 错误：0开头被转八进制，值会错乱
    private String rightJobNo;     // 正确：yml 加双引号，String 类型保留前导 0
}
```

## config/DemoConfig.java

```java
package com.example.demo.config;

import com.example.demo.prop.DemoProp;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class DemoConfig {
    @Bean
    public void printNum(DemoProp p) {
        System.out.println("二进制0b101 → " + p.getBinaryNum());         // 5
        System.out.println("八进制011 → " + p.getOctNum());             // 9
        System.out.println("十六进制0x0a → " + p.getHexNum());          // 10
        System.out.println("十进制11 → " + p.getDecNum());              // 11
        System.out.println("错误工号00123 → " + p.getWrongJobNo());     // 83（被转八进制！）
        System.out.println("正确工号\"00123\" → " + p.getRightJobNo()); // 00123（保留原值）
    }
}
```

## webEnvironment 四种模式

| 参数 | 行为 |
|------|------|
| `MOCK`（默认） | 不启 Tomcat，配合 `MockMvc` |
| `RANDOM_PORT` | 真实 Tomcat + 随机端口，配合 `TestRestTemplate` |
| `DEFINED_PORT` | 真实 Tomcat + yml 固定端口 |
| `NONE` | 不加载 Web 容器，纯 Service 测试 |

## pom.xml

```xml
<!-- SpringBoot 测试启动器，包含 JUnit5、MockMvc、TestRestTemplate 等 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>
```

## src/test/java/.../WebFullTest.java

```java
package com.example.demo;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.test.web.client.TestRestTemplate;
import org.springframework.boot.test.web.server.LocalServerPort;

// 启动真实 Tomcat，随机端口（推荐接口自动化测试）
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
class WebFullTest {

    @LocalServerPort       // 自动注入当前随机端口
    private Integer port;

    @Autowired
    private TestRestTemplate restTemplate; // 真实 HTTP 客户端，模拟浏览器

    @Test
    void testHelloApi() {
        // 拼接完整请求 URL
        String url = "http://localhost:" + port + "/hello";
        // 发送 GET 请求
        String resp = restTemplate.getForObject(url, String.class);
        System.out.println("接口返回：" + resp);
    }
}
```

## 常用断言速查

| 类型 | API | 说明 |
|------|-----|------|
| 状态码 200 | `status().isOk()` | 接口正常返回 |
| 状态码 404 | `status().isNotFound()` | 接口不存在 |
| 状态码 400 | `status().isBadRequest()` | 请求参数错误 |
| 状态码 500 | `status().isInternalServerError()` | 服务器内部异常 |
| 纯文本 | `content().string("xxx")` | 校验返回的普通字符串 |
| JSON 字段 | `jsonPath("$.field").value(x)` | 校验 JSON 中某个字段的值 |
| JSON 数组 | `jsonPath("$.data[0].name").value("x")` | 校验 JSON 数组第一个元素 |
| 响应头存在 | `header().exists("token")` | 判断响应头是否存在 |
| 响应头值 | `header().string("Content-Type", "application/json")` | 校验响应头的值 |
| 文件下载头 | `header().string("Content-Disposition", "attachment;filename=test.xlsx")` | 校验下载文件名 |

## 对比

| | MockMvc（MOCK） | TestRestTemplate（RANDOM_PORT） |
|------|------|------|
| Tomcat | 不启动 | 真实启动 |
| 端口 | 无 | `@LocalServerPort` 随机 |
| 速度 | 快 | 慢 |
| 适用 | Controller 逻辑自测 | 完整链路集成测试 |

```java
package com.example.demo;
```

```java
@SpringBootTest
@Transactional  // 配合回滚，随机数据不入库
class UserServiceRandomTest {

    @Autowired
    private UserService userService;

    @Test
    void testAddUserRandom() {
        User user = new User();
        int n = ThreadLocalRandom.current().nextInt(10000, 99999); // 5 位随机数
        user.setUsername("测试用户_" + n);
        user.setAge(ThreadLocalRandom.current().nextInt(18, 61));  // 随机年龄 18~60
        // 随机手机号后 8 位
        user.setMobilePhone("138" + ThreadLocalRandom.current().nextLong(10000000, 99999999));

    }
}
```

```
└── application-test.yml
```

## 是什么

Spring 自带轻量 JDBC 工具，封装了连接管理、异常处理、ResultSet 遍历。适合简单 SQL、测试快速造数据。

## 常用方法

| 方法 | 用途 |
|------|------|
| `update(sql, args...)` | 增删改 |
| `queryForMap(sql, args...)` | 查单行 → Map |
| `queryForList(sql, args...)` | 查多行 → List\<Map\> |
| `batchUpdate(sql, List<Object[]>)` | 批量插入 |

## src/test/java/.../JdbcTemplateTest.java

```java
package com.example.demo;

import com.github.javafaker.Faker;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.test.context.ActiveProfiles;
import org.springframework.transaction.annotation.Transactional;
import java.util.*;

@SpringBootTest
@ActiveProfiles("test")  // H2 内存库
@Transactional           // 测试结束自动回滚
class JdbcTemplateTest {

    @Autowired
    private JdbcTemplate jdbcTemplate; // Spring 自动装配，无需手动管理连接

    private final Faker faker = new Faker(java.util.Locale.CHINA); // 中文随机数据

    // 新增单条数据
    @Test
    void testInsert() {
        String sql = "INSERT INTO user (username, mobile_phone, age) VALUES (?,?,?)"; // ? 占位防 SQL 注入
        int rows = jdbcTemplate.update(sql,
            faker.name().fullName(),                         // 第1个 ? 的值
            faker.phoneNumber().cellPhone(),                 // 第2个 ? 的值
            faker.number().numberBetween(18, 60));           // 第3个 ? 的值
        System.out.println("插入行数：" + rows);               // 返回受影响行数
    }

    // 批量插入测试数据
    @Test
    void testBatchInsert() {
        String sql = "INSERT INTO user (username, mobile_phone, age) VALUES (?,?,?)";
        List<Object[]> batch = new ArrayList<>();
        for (int i = 0; i < 10; i++) {                      // 造 10 条随机数据
            batch.add(new Object[]{
                faker.name().fullName(),
                faker.phoneNumber().cellPhone(),
                faker.number().numberBetween(18, 60)
            });
        }
        jdbcTemplate.batchUpdate(sql, batch);                // 一次性批量执行
    }

    // 查询单行 → Map
    @Test
    void testQuerySingle() {
        Map<String, Object> row = jdbcTemplate.queryForMap(
            "SELECT * FROM user WHERE id = ?", 1);           // 查询 id=1 的用户
        System.out.println("用户名：" + row.get("username")); // key 为数据库字段名
    }

    // 查询多行 → List
    @Test
    void testQueryList() {
        List<Map<String, Object>> list = jdbcTemplate.queryForList(
            "SELECT * FROM user WHERE age > ?", 30);         // 查询年龄大于 30 的用户
        list.forEach(System.out::println);                   // 逐行打印
    }

    // 修改和删除
    @Test
    void testUpdateAndDelete() {
        jdbcTemplate.update("UPDATE user SET age = ? WHERE id = ?", 30, 1); // 修改 id=1 的年龄
        jdbcTemplate.update("DELETE FROM user WHERE id = ?", 1);            // 删除 id=1
    }
}
```

## 定位

简单操作/测试用 JdbcTemplate，复杂业务查询用 MyBatis。
