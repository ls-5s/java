# SpringBoot Actuator 全套知识点 + 可直接运行代码

Actuator 是 SpringBoot 内置监控组件，暴露一系列 `/actuator/xxx` 接口（端点 endpoint），用来查看服务状态。Spring Boot Admin 底层依赖它。

---

## 1、基础概念

- 端点访问格式：`/actuator/端点名`
- 默认只开放 `/actuator/health`、`/actuator/info`
- 访问示例：`http://localhost:8080/actuator/health`

## 2、引入依赖

```xml
<!-- pom.xml -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```

## 3、基础配置（application.yml）

```yaml
management:
  endpoints:
    web:
      exposure:
        include: "*"  # 生产环境不要写*，按需开放
  endpoint:
    health:
      show-details: always  # health 显示完整详情
```

## 4、info 端点（项目信息）

作用：展示项目自定义信息。

### YML 静态配置

```yaml
info:
  app-name: demo-project
  author: test
  version: 1.0.0
```

访问：`/actuator/info`

### Java 代码动态填充（可选）

```java
import org.springframework.boot.actuate.info.Info;
import org.springframework.boot.actuate.info.InfoContributor;
import org.springframework.stereotype.Component;

@Component
public class CustomInfo implements InfoContributor {
    @Override
    public void contribute(Info.Builder builder) {
        builder.withDetail("time", System.currentTimeMillis())
               .withDetail("env", "dev");
    }
}
```

## 5、health 健康端点【最重要】

作用：检测服务依赖是否正常（数据库、Redis、消息队列等）。

路径：`/actuator/health`

内置检测器：`db`（数据库）、`redis`、`diskSpace`（磁盘空间）

返回状态：`UP` 正常 / `DOWN` 异常

### 自定义健康检查

```java
import org.springframework.boot.actuate.health.Health;
import org.springframework.boot.actuate.health.HealthIndicator;
import org.springframework.stereotype.Component;

@Component
public class CustomHealthIndicator implements HealthIndicator {
    @Override
    public Health health() {
        boolean ok = true;
        if (ok) {
            return Health.up().withDetail("serviceStatus", "正常").build();
        } else {
            return Health.down().withDetail("serviceStatus", "异常").build();
        }
    }
}
```

## 6、metrics 指标端点

作用：采集运行指标（JVM 内存、CPU、请求次数、线程数等）。

- 查看全部指标：`/actuator/metrics`
- 查看某个指标：`/actuator/metrics/jvm.memory.used`

### 自定义业务指标

```java
import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.MeterRegistry;
import org.springframework.stereotype.Service;

@Service
public class MetricService {
    private final Counter orderCounter;

    public MetricService(MeterRegistry registry) {
        orderCounter = registry.counter("business.order.create");
    }

    public void createOrder() {
        // 订单创建，指标+1
        orderCounter.increment();
    }
}
```

## 7、自定义 Endpoint

```java
import org.springframework.boot.actuate.endpoint.annotation.Endpoint;
import org.springframework.boot.actuate.endpoint.annotation.ReadOperation;
import java.util.HashMap;
import java.util.Map;

@Endpoint(id = "custom")  // 访问路径 /actuator/custom
@Component
public class CustomEndpoint {

    @ReadOperation  // GET 请求
    public Map<String, Object> getData() {
        Map<String, Object> map = new HashMap<>();
        map.put("serverTime", System.currentTimeMillis());
        map.put("msg", "自定义监控端点");
        return map;
    }
}
```

## 面试极简总结

1. Actuator = 原始监控接口（JSON）
2. Spring Boot Admin = Actuator 的可视化网页
3. health：存活健康检测；info：项目描述；metrics：性能指标；endpoint 支持自定义
4. **生产环境严禁 `include: "*"`，最小化开放端点，保障安全**
